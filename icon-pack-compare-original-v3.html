Иконки в твоём дереве категорий

Настоящие SVG из четырёх разных бесплатных библиотек — без подмены одним набором. Содержание и вложенность повторяют видимые строки присланного скриншота.

100% локальных SVG: в каждом из 4 наборов используются 10 реальных пар Outline/Fill. Файл полностью автономный: сеть не нужна, никакие изображения не скачиваются после открытия. Отображаются только категории, видимые на твоём скриншоте.
Источники и лицензии: Phosphor (MIT) · Remix (Remix Icon License) · Heroicons (MIT) · Fluent UI (MIT).

Для Heroicons «Прогулка» показана символом карты, «Перемещение» — грузовиком: в этом наборе нет точных аналогов отдельных иконок из оригинального дерева. Никаких выдуманных SVG не используется.

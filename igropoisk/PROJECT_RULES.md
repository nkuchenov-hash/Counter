# Игропоиск — постоянные правила продукта

Этот документ определяет обязательную структуру сайта и каждой страницы игры. Изменения интерфейса и сборщиков не должны нарушать эти правила.

## 1. Рейтинги

На сайте существуют только два рейтинга:

1. **Рейтинг Игропоиска** — интегральная оценка по шкале 0–10, рассчитанная на основе оценок авторитетных изданий и нормализованная единой методикой.
2. **Рейтинг игроков Игропоиска** — средняя оценка зарегистрированных пользователей сайта.

Отдельной карточки «критики» нет. Рейтинг игроков не отображается вообще, пока не получена хотя бы одна пользовательская оценка. Нулевое значение и пустая карточка запрещены. В hero рейтинг выводится компактно белым текстом, без крупных белых карточек.

## 2. Hero страницы игры и главной

Hero — обязательный слайдер. Он использует:

- официальный key art или hero image;
- официальный header;
- 4–6 реальных скриншотов игры.

Слайды автоматически переключаются примерно раз в 5–6 секунд. Пользователь может переключить фон вручную через индикаторы. Текст, кнопки и рейтинг остаются неподвижными.

## 3. Обязательная структура страницы игры

Страница игры является самостоятельным мини-сайтом и содержит вкладки:

- Всё об игре;
- Медиа;
- Статьи;
- Обзоры;
- Гайды;
- Советы;
- Новости.

Вкладка «Всё об игре» обязательно содержит:

- краткое описание;
- расширенный интегрированный текст об игре;
- сюжет или структуру кампании;
- особенности игрового процесса;
- дату выхода и статус релиза;
- жанры;
- платформы;
- разработчика и издателя;
- обязательную галерею реальных скриншотов;
- раскрываемый список использованных источников.

Вкладка «Медиа» обязательно содержит отдельные блоки:

- скриншоты;
- официальные трейлеры, gameplay-видео или дневники разработчиков.

Страница без скриншотов не считается готовой. Для крупной опубликованной игры желательно минимум 6 скриншотов и минимум одно официальное видео.

## 4. Редакционный фреймворк 10–20 источников

Собственный текст Игропоиска не должен быть пересказом одного источника. Для каждой интегрированной статьи или основного текста страницы анализируются **10–20 источников**.

### Источники первого приоритета

1. Официальный сайт игры.
2. Официальный сайт разработчика.
3. Официальный сайт издателя.
4. Официальные страницы Steam, PlayStation, Xbox, Nintendo, Epic Games Store или GOG.

### Базы и агрегаторы

- IGDB;
- RAWG;
- Metacritic;
- OpenCritic.

### Крупные зарубежные издания

- IGN;
- GameSpot;
- PC Gamer;
- Eurogamer;
- Rock Paper Shotgun;
- GamesRadar+;
- Polygon;
- Game Informer или его архивные материалы;
- другие крупные профильные издания при наличии редакционной репутации.

### Крупные русскоязычные источники

- Игромания;
- StopGame;
- GameMAG;
- DTF — только редакционные и проверяемые материалы;
- другие значимые профильные издания после проверки качества.

## 5. Правила синтеза информации

- Официальные источники имеют приоритет для дат, платформ, студий, издателей, состава изданий и официальных особенностей.
- Оценочные суждения должны подтверждаться несколькими независимыми публикациями.
- Противоречащие сведения не смешиваются молча: выбирается наиболее надёжный источник или отмечается неопределённость.
- Чужие статьи не копируются целиком.
- Игропоиск создаёт собственный интегрированный текст и раскрывает список источников.
- Для каждого факта сохраняются URL, название источника, дата публикации и дата проверки.

## 7. Стартовый каталог

Первая рабочая редакция сайта должна содержать 100–200 наиболее значимых игр разных лет. Отбор выполняется по популярности, культурной значимости, количеству надёжных публикаций и полноте доступных данных. Неизвестные проекты без достаточного покрытия не добавляются только ради количества.

Каждая игра стартового каталога должна пройти один и тот же шаблон страницы и минимальную проверку полноты:

- заполнены основные метаданные;
- есть hero и обложка;
- есть реальные скриншоты;
- есть хотя бы одно официальное видео, если оно доступно;
- есть список 10–20 проверенных источников;
- рассчитан рейтинг Игропоиска;
- рейтинг игроков отсутствует до первого пользовательского голоса.

## 8. Запрет на разрушение структуры

Дальнейшие изменения должны улучшать существующий каркас, а не заменять сайт новым прототипом. Маршруты, вкладки, модель данных и правила рейтинга считаются постоянной основой проекта.

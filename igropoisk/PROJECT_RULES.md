# Игропоиск — постоянные правила продукта

Этот документ определяет обязательную структуру сайта и каждой страницы игры. Изменения интерфейса и сборщиков не должны нарушать эти правила.

## 0. Абсолютный запрет пустых страниц

**Публикация пустой, частично заполненной, временной или «догружающейся» страницы игры запрещена.**

Страница игры не может появиться:

- на главной;
- в каталоге;
- в поиске;
- в подборках;
- по прямой публичной ссылке;
- в sitemap;
- в индексируемом HTML;

пока запись не прошла обязательный `publish gate`.

Фразы и состояния вроде «информация загружается», «скриншоты загружаются», «материалы пока не найдены», пустые вкладки, фиктивные карточки и подставные тексты на публичной странице запрещены.

Неполная игра хранится только во внутренней очереди подготовки со статусом `draft`, `collecting`, `review` или `rejected`. Публичный статус может быть только `published`.

### Обязательный publish gate

Игра может получить статус `published` только если одновременно выполнены все требования:

1. Идентичность игры подтверждена минимум двумя независимыми базами или одним официальным источником и одной крупной базой.
2. Проверено от 10 до 20 реальных источников.
3. Среди источников обязательно присутствуют доступные официальные страницы игры, разработчика или издателя.
4. Заполнены название, альтернативные названия при наличии, дата или статус релиза, жанры, платформы, разработчик и издатель.
5. Есть краткое описание и отдельный полноценный интегрированный обзор игры.
6. Есть раздел о сюжете, структуре кампании или корректное объяснение отсутствия сюжетной кампании.
7. Есть минимум четыре содержательные особенности игрового процесса.
8. Есть hero-изображение, обложка и минимум шесть реальных скриншотов.
9. Есть минимум одно официальное видео, если оно существует в официальных источниках.
10. Рассчитан рейтинг Игропоиска либо явно зафиксировано, что данных для рейтинга недостаточно. Пустая карточка рейтинга не создаётся.
11. Все публичные вкладки либо содержат реальные материалы, либо вкладка вообще не создаётся. Пустая вкладка запрещена.
12. Для редакционного текста сохранён список источников с URL, названием, датой публикации, датой проверки и уровнем доверия.
13. Автоматическая проверка полноты завершилась без ошибок.
14. Запись прошла редакционную проверку или формальную автоматическую проверку качества, утверждённую проектом.

Если хотя бы одно обязательное условие не выполнено, страница не публикуется вообще.

## 1. Рейтинги

На сайте существуют только два рейтинга:

1. **Рейтинг Игропоиска** — интегральная оценка по шкале 0–10, рассчитанная на основе оценок авторитетных изданий и нормализованная единой методикой.
2. **Рейтинг игроков Игропоиска** — средняя оценка зарегистрированных пользователей сайта.

Отдельной карточки «критики» нет. Рейтинг игроков не отображается вообще, пока не получена хотя бы одна пользовательская оценка. Нулевое значение и пустая карточка запрещены. В hero рейтинг выводится компактно белым текстом, без крупных белых карточек.

## 2. Hero страницы игры и главной

Hero — обязательный слайдер. Он использует:

- официальный key art или hero image;
- официальный header;
- 4–6 реальных скриншотов игры.

Слайды автоматически переключаются примерно раз в 5–6 секунд. Пользователь может переключить фон вручную через индикаторы. Текст, кнопки и рейтинг остаются неподвижными.

## 3. Обязательная структура страницы игры

Страница игры является самостоятельным мини-сайтом. Вкладка создаётся только при наличии реального содержимого.

Возможные вкладки:

- Всё об игре;
- Медиа;
- Статьи;
- Обзоры;
- Гайды;
- Советы;
- Новости.

Вкладка «Всё об игре» обязательно содержит:

- краткое описание;
- расширенный интегрированный текст об игре;
- сюжет или структуру кампании;
- особенности игрового процесса;
- дату выхода и статус релиза;
- жанры;
- платформы;
- разработчика и издателя;
- обязательную галерею реальных скриншотов;
- раскрываемый список использованных источников.

Вкладка «Медиа» обязательно содержит отдельные блоки:

- скриншоты;
- официальные трейлеры, gameplay-видео или дневники разработчиков.

Страница без скриншотов не считается готовой. Для опубликованной страницы требуется минимум шесть скриншотов. Видео обязательно, если оно существует в официальных источниках.

## 4. Редакционный фреймворк 10–20 источников

Собственный текст Игропоиска не должен быть пересказом одного источника. Для каждой интегрированной статьи или основного текста страницы анализируются **10–20 источников**.

### Источники первого приоритета

1. Официальный сайт игры.
2. Официальный сайт разработчика.
3. Официальный сайт издателя.
4. Официальные страницы Steam, PlayStation, Xbox, Nintendo, Epic Games Store или GOG.

### Базы и агрегаторы

- IGDB;
- RAWG;
- Metacritic;
- OpenCritic.

### Крупные зарубежные издания

- IGN;
- GameSpot;
- PC Gamer;
- Eurogamer;
- Rock Paper Shotgun;
- GamesRadar+;
- Polygon;
- Game Informer или его архивные материалы;
- другие крупные профильные издания при наличии редакционной репутации.

### Крупные русскоязычные источники

- Игромания;
- StopGame;
- GameMAG;
- DTF — только редакционные и проверяемые материалы;
- другие значимые профильные издания после проверки качества.

## 5. Правила синтеза информации

- Официальные источники имеют приоритет для дат, платформ, студий, издателей, состава изданий и официальных особенностей.
- Оценочные суждения должны подтверждаться несколькими независимыми публикациями.
- Противоречащие сведения не смешиваются молча: выбирается наиболее надёжный источник или отмечается неопределённость.
- Чужие статьи не копируются целиком.
- Игропоиск создаёт собственный интегрированный текст и раскрывает список источников.
- Для каждого факта сохраняются URL, название источника, дата публикации и дата проверки.
- Список поисковых ссылок не считается анализом источников.
- Автоматически сгенерированный текст без сохранённых доказательств источников не допускается к публикации.

## 7. Стартовый каталог

Первая рабочая редакция сайта должна содержать 100–200 наиболее значимых игр разных лет. Отбор выполняется по популярности, культурной значимости, количеству надёжных публикаций и полноте доступных данных. Неизвестные проекты без достаточного покрытия не добавляются только ради количества.

Количество никогда не имеет приоритета над полнотой. Если publish gate прошли только 20 игр, публично показываются только эти 20. Остальные не существуют для посетителя до завершения подготовки.

Каждая игра стартового каталога проходит один и тот же полный цикл:

1. обнаружение;
2. идентификация и удаление дублей;
3. сбор 10–20 источников;
4. нормализация фактов;
5. подготовка интегрированного текста;
6. сбор медиа;
7. расчёт рейтинга;
8. проверка publish gate;
9. публикация.

## 8. Реализация publish gate

Сборщик обязан записывать две отдельные базы:

- внутреннюю базу кандидатов и черновиков;
- публичный каталог только из записей со статусом `published` и `gate_passed: true`.

Фронтенд дополнительно повторно проверяет publish gate. Даже если ошибочная запись попала в публичный JSON, интерфейс обязан исключить её из каталога и запретить открытие маршрута игры.

Сборка сайта должна завершаться ошибкой, если в публичном каталоге найдена хотя бы одна неполная запись.

## 9. Запрет на разрушение структуры

Дальнейшие изменения должны улучшать существующий каркас, а не заменять сайт новым прототипом. Маршруты, вкладки, модель данных, publish gate и правила рейтинга считаются постоянной основой проекта.

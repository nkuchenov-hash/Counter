# Heroicons ↔ Fluent UI — visual decisions needed

This review contains **94 unresolved / ambiguous pairs**, derived from a complete audit of **324 Heroicons** against the **2,470 Fluent UI 24px Regular + Filled pairs** available in the current upstream catalog (2026-11-05).

**Every row is provisional.** Being visually close or sharing a word in its name does *not* establish semantic equivalence. Some Heroicons have no true Fluent equivalent. Mark **none** when all proposals are wrong rather than forcing a match.

The **40 category-relevant cases appear first**. The **54 UI-control cases** follow for completeness but are intentionally excluded from the category picker.

Images show both icon variants, as requested: Heroicons Outline/Solid and Fluent UI Regular/Filled. If a thumbnail fails to render, the identifier is retained and can be searched in [Heroicons](https://heroicons.com/) or [Fluent UI](https://github.com/microsoft/fluentui-system-icons/tree/main/assets).

**How to review:** In the last column, replace the checkbox options with the preferred candidate, or write a different Fluent icon name. The companion [complete CSV audit](HEROICONS_FLUENT_324_MAPPING.csv) includes all 324 pairs and alternatives, including 230 higher-confidence mappings.

## Implementation rules

- Preserve one semantic key per accepted pair, not per visual style.
- Require genuine matching meanings and both outline/filled variants.
- Retain existing saved category icons across library changes.
- Do not add navigation arrows, chevrons, toolbar commands or generic editor controls to the category picker.
- Do not mark provisional candidates as accepted until their silhouettes and semantics are checked.

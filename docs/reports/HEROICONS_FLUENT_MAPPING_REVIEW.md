# Heroicons → Fluent UI: mapping review

As of 2026-11-05. **This is a review document, not a claim that all candidates are equivalent.** All 324 Heroicons members in the pinned Flutter-facing enum were audited against the **2470** Fluent UI icon names having both `24_regular` and `24_filled` in upstream font mappings. Full machine-readable matrix: [HEROICONS_FLUENT_324_MAPPING.csv](HEROICONS_FLUENT_324_MAPPING.csv).

**Counts:** 230 matched by identical name, prior verified pair or curated semantic alias; **94 still need visual/semantic approval**. Every Heroicons entry has at least one *candidate* in the CSV. Candidate ≠ validated equivalent. Some concepts (e.g. national currency symbols or geographically specific globe artwork) may not have a genuinely equivalent Fluent drawing; do not silently substitute a generic symbol.

**Category UI policy:** Catalog matching and category relevance are distinct. Navigation arrows, chevrons, menus, editing controls, and similar commands remain in this mapping audit, but should not appear as selectable category subjects. Avoid forcing false pairs simply to hit 324/324.

## Acceptance criteria

1. Same recognizable object/action at ordinary category icon size (24px).
2. Both Fluent Regular and Filled variants must exist; Heroicons Outline and Solid already exist.
3. No unrelated semantic fallbacks (e.g. currency/region labels cannot be represented by a generic icon and marked equivalent without review).
4. Retain old semantic category selections and stable IDs.
5. Distinguish a technically available icon from an appropriate category icon.

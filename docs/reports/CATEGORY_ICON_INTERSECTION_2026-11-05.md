## Exclusion policy

Unmatched Fluent-only and Heroicons-only icons are not presented in the application selector or customization UI. Similar appearance without the same underlying meaning is not sufficient. Each family contains additional upstream assets that are **not selectable**. Previous device-local keys outside this catalog are retained in stored preferences, displayed with a safe folder fallback, and never mapped to unrelated concepts.

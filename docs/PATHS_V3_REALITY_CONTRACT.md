# Paths V3 reality contract

A project Path is not considered verified merely because it has stages.

For a Path to be executable:
- every unfinished stage has a verifiable completion condition;
- every action leaves a concrete result and is estimated at 30 minutes or less;
- unknown external dependencies are represented explicitly, not assumed;
- project-specific blind spots are audited before the Path is called verified;
- only bottom-level actions may later be offered to the Daily Planner.

KADR V3 additionally audits the complete commercial route: free/paid offer, product, website, payments, licensing, legal, Windows distribution, Microsoft Store, demand validation, Apple, Android/RuStore, support, and release operations.

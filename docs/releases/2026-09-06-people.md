# People settings release — 2026-09-06

People is now integrated into the canonical Settings → Account surface.

The release includes People, Circles, and Sources; person photos and contact details; birthdays and reminders; explicit phone-contact and Telegram import; and server-owned Google Contacts, Microsoft, VK, and Facebook source integrations.

External contacts remain hidden until the user explicitly adds or links them. Ignored and blocked source contacts remain suppressed on later syncs.

Final release verification runs against the clean main tree after structure-manifest regeneration. The current canonical main revision is also used for the final web publication check.
